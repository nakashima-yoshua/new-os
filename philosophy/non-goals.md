# Non-goals

Specification v0.1 intentionally does **not** attempt to:

- create a complete general-purpose operating system immediately;
- reproduce Linux, Unix, Windows, or POSIX with a cleaner implementation;
- guarantee source or binary compatibility in the native model;
- place AI or an LLM in the trusted computing base;
- maximize performance before the semantic model is validated;
- invent a new abstraction when an existing mechanism can validate the idea;
- solve every distributed-systems problem inside the kernel;
- define a final GUI, package ecosystem, programming language, or hardware ABI;
- require a microkernel implementation before the reference runtime demonstrates value.

The immediate objective is narrower: determine whether the Component / Capability / Resource / Message / State model is coherent, useful, enforceable, and practical for real software.
